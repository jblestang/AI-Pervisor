# Phase 9 expert review

Multi-domain review of VMX foundation, transfer ABI v2 hardening, and Gate B closure on the UEFI hypervisor path (`cursor/phase-9-vmx-foundation-0b4f`).

## Domains reviewed

| Domain | Scope |
|--------|--------|
| Transfer ABI | `TRANSFER_ABI_VERSION = 2`, `published_alloc_size`, loader publish binding |
| Requirements snapshot | Hypervisor reserve metadata embedded in UEFI hypervisor image |
| VMX foundation | `hv-vmx` init plan, mock backend, feature-gated init orchestration |
| Hypervisor boot split | `hv-hypervisor-boot` portable orchestration; `hv-hypervisor` re-exports |
| UEFI hypervisor entry | Full observe/validate + mock VMX init (not digest-only verify) |
| Build / CI | Embedded config generation moved to host `hv-config`; UEFI `no_std` isolation |

## Findings and disposition

### MUST FIX (applied)

1. **Transfer ABI v2** — `HypervisorTransferHeader` gains `published_alloc_size`; loader publish patches allocation size; hypervisor validates bounds against slice length.
2. **Gate B on UEFI** — `hv-hypervisor-efi` runs `boot_from_transfer_and_init_vmx()` (observe, validate, plan VMX, mock backend init) instead of transfer/digest-only verification.
3. **VMX foundation crate** — `hv-vmx` provides `VmxInitPlan`, `plan_vmx_init()`, `init_vmx()` with `MockVmxBackend` for host and firmware paths.
4. **Portable boot orchestration** — `hv-hypervisor-boot` (`no_std` + `alloc`) holds snapshot conversion, transfer boot, and VMX orchestration; `hv-hypervisor` re-exports for host tests.
5. **Requirements snapshot reserve fields** — `hypervisor_reserve_phys` / `hypervisor_reserve_bytes` bind static layout metadata into the embedded hypervisor image.

### SHOULD FIX (applied)

6. **UEFI `std` feature unification** — Hypervisor UEFI build uses path deps with `default-features = false`; embedded config is pre-generated by `tools/hv-config` into `build/hypervisor_embedded_config.rs` (mirrors loader digest pattern).
7. **Platform model `no_std`** — Runtime observe/validate paths compile without `std` for firmware consumers.
8. **Coverage and tests** — Added boot-abi transfer bounds tests, hypervisor-boot orchestration tests, VMX error/display coverage; workspace line coverage ≥ 95%.
9. **Documentation** — Architecture, platform contract, OVMF boot, and README updated for Phase 9 scope and deferred Gate C work.

### Documented (deferred)

10. **Real VMXON/EPT/VT-d** — Mock backend only; hardware VMX enablement and EPT page tables remain Gate C.
11. **VT-d / interrupt remapping enablement** — Validated in requirements compare only; no IOMMU programming.
12. **Production PCI discovery** — Unchanged from Phase 8 (legacy port scan, no bridge recursion).
13. **Requirements snapshot metadata gaps** — `partition_id` / device `kind` strings still omitted; BDF + vm_id validation only.
16. **OVMF smoke vs production requirements** — `cargo xtask ovmf-smoke-boot` builds with `configs/ovmf-smoke.yaml` (VMX/EPT optional for TCG); production `configs/qemu.yaml` Gate B + mock VMX init remains host-tested.
